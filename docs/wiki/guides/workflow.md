# Application workflow

- **Jobs:** search, filter, compare match reasons, review the description, save or dismiss. Saved jobs queue a tailored cover letter. Manually adding a posting or editing a short description also works.
- **Saved:** keep notes, open the cover letter, or manually record that you applied elsewhere.
- **Assistant:** the button in the top-right page header opens a sliding chat overlay on any page. Search collected jobs, research supplied public references, update profile facts, edit the actual LaTeX CV, and rewrite saved cover letters. Attach PDFs/text/images or paste screenshots into the composer. Conversation and unsent text/files stay with you across pages; Escape hides the pane. **New chat** clears the conversation, remembered context and unsent draft while keeping saved facts and documents. Wait for a reply or stop it first.
- **User profile:** review the canonical facts as read-only Markdown and use **Edit with assistant** to change them. New installations open here with guided onboarding; discovery waits for the essential details. Previous profile versions can be restored.
- **CV:** edit and save LaTeX source beside its PDF preview, recompile, restore versions, and download .tex or PDF.
- **Saved → job → Cover letter:** generate and edit the letter in its job detail using plain-text fields and paragraph breaks, with a preview. Save creates a version; restore appends a new version. Copy text or download PDF using the shared layout.
- **Sources:** add company boards, public job boards, HN, feeds, or X searches. Public boards also have direct site links and manual job entry. Review scan status, request counts, errors, and next scan times.
- **Settings → Backup:** export current personal content to ZIP or import a ZIP to overwrite it. Export first to retain your old content; there is no automatic backup. [Backup details](../features/backups.md).
- **Settings:** collection schedule, ChatGPT connection, generation pause, X credentials/budget, and the Web3.career API token.

No application submission, employer upload, form filling, messaging, posting, replying, following, or reacting is implemented. External posting links open normally for you to use yourself. Notifications stay in the application.


See the [feature map](../features/index.md) for the contracts and verification recipes behind these actions.
