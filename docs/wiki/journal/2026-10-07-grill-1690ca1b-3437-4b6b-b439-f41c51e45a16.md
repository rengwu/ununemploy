## Question 1

```text
Round: ZIP backup and restore
Question: What should importing a backup do when this app already contains data?
Description (Markdown source):
Your current jobs, saved status, notes, profile and documents may differ from the ZIP. Restoring a snapshot and combining two collections have different conflict rules.
Recommendation: Restore the backup as a complete snapshot, with a preview and an automatic backup of the current data before replacement. This makes recovery predictable and reversible.
Options: Restore the snapshot; back up current data first / Merge the backup into existing data / Offer both restore and merge
Selected: Something else
Notes: simply overwrite it. user should back it up themselves if they wanted to keep it.
```

## Question 3

Round: ZIP backup and restore
Question: Should the backup also carry your source configuration and application settings?
Description (Markdown source):
Alongside your requested CV, profile, scanned jobs, saved jobs and letters, this can preserve configured job sources, scan checkpoints and settings. Credentials and Codex sign-in remain on the device and are excluded. After import, scanning and generation can stay paused until you resume them.
Recommendation: Include source configuration, checkpoints and settings for a useful recovery or move to another local installation. Keep the destination's existing usage counters from decreasing.
Options: Include source configuration, checkpoints and settings / Back up the requested personal content only
