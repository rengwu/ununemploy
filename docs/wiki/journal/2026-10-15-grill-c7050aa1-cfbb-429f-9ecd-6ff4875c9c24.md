## Question 5

```text
Round: Lean cover-letter editor
Question: How should older cover letters with custom HTML/CSS layouts appear?
Description (Markdown source):
All saved versions, original content and layout source will remain stored. New edits will use one shared layout. We need to decide whether viewing an older version should still render its original appearance or use the new shared layout.
Recommendation: Render older versions in their original layout; apply the shared layout when a new edit is saved. This preserves the meaning of version history while simplifying everyday editing.
Options: Original layout for old versions; shared layout for new saves / Shared layout for all previews and exports; original layout available as an archive download
Selected: (notes only)
Notes: ignore older cover letters. this is not in use yet
```
