# Native desktop packaging — 7 October 2026

The user requested a Go webview wrapper because starting the local instance manually made the app inconvenient to use. They selected **Keep running until Quit**, with the current Mac as the first target. This authorizes a native local launcher and bundled service lifecycle; no new external hosting or application-submission behavior is introduced.

The [desktop feature](../features/desktop.md) is the current specification. A Go supervisor and Cocoa/WKWebView adapter provide a native window, menus, downloads, single-instance handling and service shutdown. The existing React/Kumo UI is served by the bundled Fastify API; the existing worker stays in a separate Node process so collection does not share the API event loop. A parent-pipe watchdog and process-group cleanup cover normal Quit and abrupt wrapper exit.

Packaging uses explicit code/runtime inputs, with no candidate evidence, credentials or application database inside the bundle. Installation uses SQLite's backup API and imports private assets into Application Support, retaining the original files and repointing development at the same canonical data. Official Codex authentication remains runtime-owned, with the same model and reasoning settings.

Native interaction checks exercised document editing, a selectable PDF preview, native Save, unsaved-edit cancellation, hidden-window operation and Quit. Automated checks cover isolated migration and lifecycle failures/restarts; see the [dated verification index](../verification/index.md) for exact build evidence and limits. The first synthetic profile had no education entries and produced the existing empty-list LaTeX error; replacing its test source with a valid minimal document verified the packaged compiler. No user source was changed for that check.

Unraid deployment remains separate and unverified. Other desktop operating systems, Intel packaging, notarization and login startup remain outside this implementation.

A final portability audit caught npm command symlinks rewritten to build-folder paths during installation. Copy operations now preserve relative links, and the builder and installer reject broken/external links. The regression suite now contains 175 passing tests. The earlier verification report retains the discovered failure; the corrected package has a separate follow-up run.
